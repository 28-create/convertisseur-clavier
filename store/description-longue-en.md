Typed a message in Hebrew while the keyboard was still on the French layout (or
the other way round)? What should be `שלום` came out as `qkuo`. Convertisseur
Clavier fixes the text in place, with no copy-paste into another tool.

**Works both ways**, with AZERTY and QWERTY layouts:

- Hebrew → Latin and Latin → Hebrew;
- AZERTY ⇄ QWERTY (Latin text typed on the wrong layout).

## Three ways to convert

- **Right-click in the page** — select text: *Convert selection* (direction
  detected), *Convert to Hebrew* or *Convert to Latin*. Inside an `input`,
  `textarea` or editable area the text is replaced in place and stays
  undoable with `Ctrl+Z`; anywhere else the result is copied and shown in a
  notification.
- **`Ctrl+Shift+H`** — converts the selection of the active field.
- **Extension popup** — paste or type text and watch the result update as you
  type; one-click *Copy*. Pick the mode (automatic, to Hebrew, to Latin,
  AZERTY ⇄ QWERTY) and the layout.

## Fully offline, no data collected

Conversions are computed in your browser from embedded tables: **no server, no
account, no analytics, no advertising, no network request**. The clipboard is
used only when you trigger a conversion, and your settings stay on your own
machine (`chrome.storage.local`). Full policy:
https://28-create.github.io/convertisseur-clavier/confidentialite.html

## The same tool everywhere

The site https://28-create.github.io/convertisseur-clavier/ offers the same page
as a web app (nothing to install), and a Windows application can additionally
convert the clipboard anywhere — Word, a mail client or the Windows search bar —
with `Ctrl+Alt+H`.

## Limits

- The extension only acts inside web pages: menus in Word, desktop
  applications and Windows belong to those programs.
- `chrome://`, `edge://`, the Chrome Web Store and the PDF viewer do not let
  extensions read the page.
- Firefox is not supported (Chrome / Edge, Chromium version).
