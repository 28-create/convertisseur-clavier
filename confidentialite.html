Politique de confidentialité

Convertisseur Clavier — Latin ⇄ Hébreu · dernière mise à jour : 19 octobre 2026

Aucune donnée ne sort de votre appareil : ni serveur, ni compte, ni statistique, ni publicité, ni traceur.

Cette page couvre la page web, l'application Windows (ConvertisseurClavier-X.Y.Z.exe, Setup_ConvertisseurClavier-X.Y.Z.exe) et l'extension navigateur Chrome / Edge.

Données collectées

Aucune. Le Convertisseur Clavier ne collecte, ne transmet, ne vend et ne partage aucune donnée personnelle. Il ne demande ni compte, ni adresse e-mail, ni identifiant.

Ce qui est traité, et où

  • Les conversions sont calculées localement, à partir de tables embarquées.
  • Le presse-papiers est lu et écrit sur une action explicite de votre part : Ctrl+Alt+H dans l'application, ou le menu clic droit de l'extension.
  • Si vous activez la surveillance avant Ctrl+V (option du Setup), le guetteur lit le presse-papiers localement, quand son contenu change et lorsque vous appuyez sur Ctrl+V, uniquement pour calculer une proposition. Rien n'est journalisé ni envoyé ; le presse-papiers n'est réécrit que si vous choisissez « Convertir et coller ».
  • Aucun texte converti n'est journalisé, envoyé, ni conservé.

Hébergement et tiers

La page web est publiée par GitHub Pages. Comme tout hébergeur, GitHub peut journaliser techniquement les requêtes HTTP (adresse IP, agent utilisateur) pour fournir et protéger le service ; nous n'avons pas accès à ces journaux et n'en tirons aucune statistique. Voir la politique de confidentialité de GitHub. Aucun autre tiers n'intervient : pas de régie publicitaire, pas d'outil de mesure d'audience, pas de police d'écriture distante.

Vos droits (RGPD)

Aucune donnée personnelle n'étant traitée, il n'y a rien à consulter, corriger, exporter ou supprimer. Pour toute question, ouvrez une issue sur le dépôt.

Modifications

Privacy policy

Last updated: 19 October 2026

Nothing ever leaves your device: no server, no account, no analytics, no advertising, no tracker.

The Convertisseur Clavier (web page, Windows application, browser extension for Chrome / Edge) collects no data at all. Conversions run locally from embedded tables.

  • Clipboard: read and written when you explicitly trigger a conversion (Ctrl+Alt+H in the application, or the extension's right-click menu). If you enable the optional Ctrl+V watcher, it reads the clipboard locally when the content changes and when you press Ctrl+V, only to compute a conversion proposal. Nothing is logged or sent; the clipboard is rewritten only if you choose "Convert and paste".
  • Stored on your device: your settings (localStorage in the page, chrome.storage.local in the extension). Clearing site data or uninstalling removes them.
  • Extension permissions: contextMenus, clipboardWrite, storage, and page access via content_scripts to read the selection and replace the text in the active field — only when you ask for it. No remote code, no network request.
  • Hosting: the web page is served by GitHub Pages, which may keep standard technical request logs; we have no access to them. No other third party is involved.
  • Your rights: since no personal data is processed, there is nothing to access or delete. For any question, open an issue on the repository.
